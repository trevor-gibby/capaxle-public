# @capaxle/adapter-http

Projects compiled capabilities as HTTP endpoints and produces OpenAPI and discovery data.

This is an alpha package; APIs may change between alpha releases. The `alpha`
dist-tag follows the latest published alpha, so it can point to a newer version over time.

```sh
npm install @capaxle/adapter-http@alpha
```

See the [project overview and @capaxle/adapter-http guide](https://github.com/trevor-gibby/capaxle-public#package-adapter-http)
for its place in Capaxle and a basic usage example.
