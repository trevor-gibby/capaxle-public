# @capaxle/compiler

Discovers capability files, validates schemas, compiles projects, and builds artifacts.

This is an alpha package; APIs may change between alpha releases. The `alpha`
dist-tag follows the latest published alpha, so it can point to a newer version over time.

```sh
npm install @capaxle/compiler@alpha
```

See the [project overview and @capaxle/compiler guide](https://github.com/trevor-gibby/capaxle-public#package-compiler)
for its place in Capaxle and a basic usage example.
