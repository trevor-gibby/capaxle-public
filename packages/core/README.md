# @capaxle/core

Defines the TypeScript capability authoring API, `defineCapability`, and public context types.

This is an alpha package; APIs may change between alpha releases. The `alpha`
dist-tag follows the latest published alpha, so it can point to a newer version over time.

```sh
npm install @capaxle/core@alpha
```

See the [project overview and @capaxle/core guide](https://github.com/trevor-gibby/capaxle-public#package-core)
for its place in Capaxle and a basic usage example.
