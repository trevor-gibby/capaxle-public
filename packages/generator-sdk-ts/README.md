# @capaxle/generator-sdk-ts

Generates the TypeScript HTTP SDK and declarations for the internal capability facade.

This is an alpha package; APIs may change between alpha releases. The `alpha`
dist-tag follows the latest published alpha, so it can point to a newer version over time.

```sh
npm install @capaxle/generator-sdk-ts@alpha
```

See the [project overview and @capaxle/generator-sdk-ts guide](https://github.com/trevor-gibby/capaxle-public#package-generator-sdk-ts)
for its place in Capaxle and a basic usage example.
