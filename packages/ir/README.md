# @capaxle/ir

Defines the JSON-only Capability IR and validation, canonicalization, and semantic-hash helpers.

This is an alpha package; APIs may change between alpha releases. The `alpha`
dist-tag follows the latest published alpha, so it can point to a newer version over time.

```sh
npm install @capaxle/ir@alpha
```

See the [project overview and @capaxle/ir guide](https://github.com/trevor-gibby/capaxle-public#package-ir)
for its place in Capaxle and a basic usage example.
