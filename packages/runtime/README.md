# @capaxle/runtime

Builds the registry and shared policy-enforcing kernel used for capability invocation.

This is an alpha package; APIs may change between alpha releases. The `alpha`
dist-tag follows the latest published alpha, so it can point to a newer version over time.

```sh
npm install @capaxle/runtime@alpha
```

See the [project overview and @capaxle/runtime guide](https://github.com/trevor-gibby/capaxle-public#package-runtime)
for its place in Capaxle and a basic usage example.
