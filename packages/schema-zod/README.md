# @capaxle/schema-zod

Provides Zod, portable schema authoring helpers, and the Zod compiler provider.

This is an alpha package; APIs may change between alpha releases. The `alpha`
dist-tag follows the latest published alpha, so it can point to a newer version over time.

```sh
npm install @capaxle/schema-zod@alpha
```

See the [project overview and @capaxle/schema-zod guide](https://github.com/trevor-gibby/capaxle-public#package-schema-zod)
for its place in Capaxle and a basic usage example.
